# CareFlow – Clinical Pathway Process Mining

CareFlow is a healthcare process mining project that analyzes hospital event logs to understand patient journeys, discover clinical workflows, and identify potential process inefficiencies.

## Features
- Hospital workflow visualization
- Clinical activity analysis
- Triage rework detection
- Interactive Streamlit dashboard
- BigQuery data integration
- dbt data transformation and testing

## Technologies Used
- Python
- Pandas
- PM4Py
- Streamlit
- SQL
- Google BigQuery
- dbt

## Project Results
- 1,209 hospital events analyzed
- 200 unique patients
- 27 patients identified with repeated triage events

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run src/main.py
```

## Objective

To use process mining and data analytics to understand healthcare workflows and identify opportunities for process improvement.
